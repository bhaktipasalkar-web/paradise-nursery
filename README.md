# Paradise Nursery 🌿

Paradise Nursery is a dynamic shopping cart web application for an online houseplant shop. It lets customers browse plants across multiple categories, view details like images, names, descriptions, and prices, add items to a cart, and manage quantities in real time — all built with React and Redux Toolkit.

## Project Name

**Paradise Nursery**

## About the Project

Paradise Nursery brings the experience of browsing a boutique plant shop online. Customers can explore houseplants grouped into categories such as Air-Purifying Plants, Low-Maintenance Plants, and Aromatic Plants, add their favorites to a shopping cart, and adjust quantities or remove items — with the cart total updating instantly.

## Features

- Landing page with the Paradise Nursery brand and a "Get Started" call to action
- About Us page describing the company
- Product listing page with plants grouped into categories, each with a thumbnail, name, and price
- "Add to Cart" functionality with a live-updating cart icon
- Full shopping cart page: adjust quantities, remove items, see per-item and total cost
- State management handled with Redux Toolkit (`CartSlice.jsx`)

## Tech Stack

- React
- Redux Toolkit
- React Router
- CSS3
